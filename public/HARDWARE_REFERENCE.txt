/* ============================================
   BLE服务UUID
   ============================================

   服务UUID: 0000ffe0-0000-1000-8000-00805f9b34fb
   特征UUID: 0000ffe1-0000-1000-8000-00805f9b34fb

   前端JavaScript连接代码:
   ```javascript
   const device = await navigator.bluetooth.requestDevice({
     acceptAllDevices: true,
     optionalServices: ['0000ffe0-0000-1000-8000-00805f9b34fb']
   });

   const server = await device.gatt.connect();
   const service = await server.getPrimaryService('0000ffe0-0000-1000-8000-00805f9b34fb');
   const characteristic = await service.getCharacteristic('0000ffe1-0000-1000-8000-00805f9b34fb');

   characteristic.addEventListener('characteristicvaluechanged', handler);
   await characteristic.startNotifications();
   ```

*/

/* ============================================
   数据格式
   ============================================

   STM32发送格式:
   - T:25 H:60  → 温度25°C, 湿度60%
   - START      → 开始传输确认
   - STOP       → 停止传输确认
   - ERR        → DHT11读取错误

   前端解析代码:
   ```javascript
   const match = text.match(/T:(\d+)\s*H:(\d+)/);
   if (match) {
     const temperature = parseInt(match[1]);
     const humidity = parseInt(match[2]);
   }
   ```

   前端发送命令:
   - 发送 '1' → 开始传输
   - 发送 '0' → 停止传输

   ```javascript
   const encoder = new TextEncoder('utf-8');
   await characteristic.writeValue(encoder.encode('1'));
   ```

*/

/* ============================================
   控制流程
   ============================================

   1. 默认状态:
      - LED闪烁 (500ms周期)
      - 不传输数据
      - 等待连接

   2. 发送 '1' (开始):
      - LED常亮
      - 每2秒发送一次 T:xx H:xx
      - 直到收到停止命令

   3. 发送 '0' (停止):
      - LED常灭
      - 停止传输数据
      - 等待下一次开始命令

   4. 发送其他内容:
      - 回到默认闪烁状态

*/

/* ============================================
   常见问题排查
   ============================================

   Q: 电脑搜不到蓝牙设备?
   A: 1. 手机已连接会占用设备, 先断开手机
      2. 给模块重新上电重启广播
      3. Windows BLE搜索慢, 等待10秒以上

   Q: 连接后收不到数据?
   A: 1. 检查是否发送了 '1' 开始命令
      2. 检查UUID是否正确
      3. 查看串口调试输出

   Q: 数据显示乱码?
   A: 检查波特率设置 (JDY-18默认9600)

   Q: iPhone能用吗?
   A: 不能, Safari完全不支持Web Bluetooth
      需要开发React Native原生APP

*/
